# birthday_lookup
公历生日转农历，逐年查询对应农历生日的公历日期

## 项目简介
纯前端静态网页工具。
1. 输入【公历出生日期】
2. 程序自动把公历生日换算成对应的农历（月、日、是否闰月）
3. 设置年龄起止范围，批量计算：每一岁时，**当年这个农历生日对应的公历日期**
> 适合：按农历过生日的人，查询每年农历生日落到哪一天（公历）
无需后端，浏览器直接打开，可部署 GitHub Pages。

## 功能特性
- ✅ 输入公历生日，自动解析为农历（自动识别是否闰月出生）
- ✅ 自定义起始年龄、结束年龄批量查询
- ✅ 输出：周岁、农历生日、对应公历日期、星期
- ✅ 自动处理闰月生日（若某一年没有该闰月，给出提示）
- ✅ 范围：1900 ~ 2100 年
- ✅ 移动端友好，无打包，原生网页

## 使用方法
### 本地运行
1. 克隆仓库
```bash
git clone https://github.com/dxiangwiki/birthday_lookup.git
cd birthday_lookup
```
2. 双击打开 `index.html`
3. 填写公历出生日期，设置年龄范围，点击查询

### GitHub Pages 在线访问
仓库设置 → Pages，选择 main 分支，部署后直接在线使用。

## 示例
输入公历生日：`2004-07-20`，起始年龄 20，结束年龄 22
程序自动算出该公历是农历六月初四，然后输出：
```
20岁：农历六月初四 → 公历2024年07月09日 周二
21岁：农历六月初四 → 公历2025年06月29日 周日
22岁：农历六月初四 → 公历2026年07月18日 周六
```

## 技术栈
HTML + CSS + JavaScript + lunisolar.js（CDN引入，农历公历互转库）
